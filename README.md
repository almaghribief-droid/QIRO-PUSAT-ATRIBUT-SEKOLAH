# QIRO — Pusat Atribut Sekolah

Website katalog QIRO untuk kebutuhan atribut dan perlengkapan administrasi sekolah, madrasah, pesantren, kampus, dan lembaga pendidikan.

## Kategori
- Stopmap sekolah / madrasah
- Piagam penghargaan
- Sertifikat
- Map rapor
- Map ijazah
- Atribut custom identitas lembaga
